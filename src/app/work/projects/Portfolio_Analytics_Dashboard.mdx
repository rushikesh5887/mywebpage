## Project Summary

I built an interactive portfolio analytics dashboard to transform transaction-level investment data into a structured decision-support system. The application integrates portfolio holdings, mutual funds, transaction history, dividends, and profit-and-loss data into a single analytical interface.

The dashboard was developed in Python using Pandas, NumPy, Plotly, and Streamlit and deployed as a live web application through Streamlit Community Cloud.

## Business and Analytical Impact

Investment data is often fragmented across brokerage statements, transaction ledgers, spreadsheets, and manually maintained records. This makes it difficult to obtain a consistent view of portfolio performance and understand how capital allocation, returns, dividends, and historical investment decisions interact.

The dashboard addresses this by creating a repeatable analytical workflow that converts raw financial records into interactive portfolio intelligence. The same approach can be adapted to other domains where operational data must be transformed into usable decision-support tools.

## Skills and Technologies

* **Data Analytics:** Portfolio valuation, realized and unrealized P&L, allocation analysis, return calculations, and historical investment analysis
* **Financial Data Processing:** Transaction-level data cleaning, aggregation, reconciliation, and metric generation
* **Python:** `pandas`, `numpy`, and structured data-processing workflows
* **Interactive Visualization:** `Plotly` and Streamlit-based interactive charts and dashboards
* **Dashboard Development:** Built a multi-section analytical interface for current holdings, historical investments, mutual funds, dividends, and performance
* **Data Engineering:** Designed reusable CSV-based input pipelines connecting raw transaction data with analytical outputs
* **Deployment:** Git-based version control and deployment through Streamlit Community Cloud

## What I Built

* **Portfolio analytics engine:** Developed calculations for invested capital, current valuation, unrealized P&L, and portfolio-level performance metrics.
* **Equity portfolio analysis:** Built interactive views of individual holdings, allocation, gains and losses, and portfolio concentration.
* **Mutual fund analytics:** Created dedicated analysis of invested amounts, current valuation, and returns across mutual fund holdings.
* **Dividend analytics:** Integrated dividend transaction data to provide historical dividend analysis and income visibility.
* **Historical investment analysis:** Transformed transaction-level ledger data into yearly investment and performance views.
* **Interactive visual analytics:** Used Plotly and Streamlit to create dynamic charts and user-controlled views rather than static reports.
* **Deployable data product:** Converted the analytical workflow into a publicly accessible web application using GitHub and Streamlit Community Cloud.

## Challenges and Learnings

A key challenge was transforming heterogeneous transaction records into a consistent analytical structure while preserving the relationship between investments, current holdings, dividends, and profit-and-loss records.

The project required careful data cleaning, aggregation, reconciliation, and handling of edge cases such as missing transactions and different asset categories. It also reinforced the importance of separating the data-processing layer from the visualization layer so that analytical calculations remain reusable as the dashboard evolves.

The deployment process further extended the project from a local analytical script into a reproducible and accessible data product using Git, GitHub, and Streamlit Community Cloud.

## Outcome

The result is a live interactive portfolio analytics application that converts raw investment records into a structured decision-support interface.

The project demonstrates an end-to-end workflow covering data ingestion, cleaning, analytical modeling, visualization, application development, version control, and cloud deployment.
